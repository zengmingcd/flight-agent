# flight-agent
This is an AI Agent practice project.

## Goal

Convert natural language flight requests into validated structured data using OpenAI structured outputs.

Tech Stack
- Python 3.12
- FastAPI
- OpenAI API
- Pydantic

## Run the example

1. Copy `app/.env.example` to `app/.env` and set `OPENAI_API_KEY`.
2. Activate the project virtual environment with `source .venv/bin/activate`.
3. Install the dependencies with `pip install -r requirements.txt`.
4. Run the application with `python app/main.py`.
